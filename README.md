# Axiom Cosmetics (Fabric 1.21.11)

**No cheats.** Cosmetics + Lyrics client.

## Controls
| Key | Action |
|-----|--------|
| **Right Shift** | ClickGUI (modules) |
| **I** | Knife inspect animation |
| **K** | Lyrics menu |

## Modules
- **Fullbright** — max gamma
- **Color Grading** — soft film vignette/tint
- **Knives** — Karambit, Bayonet, M9, Skeleton, Butterfly, 3D Sword + inspect
- **Lyrics** — Spotify / Windows media lyrics

## Language
DE | EN toggle in the top-right of the ClickGUI.

## Build
GitHub Actions / `gradle build`
